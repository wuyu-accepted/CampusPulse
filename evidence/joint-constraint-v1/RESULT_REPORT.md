# Profile × 上一时点状态配对实验

## 实验问题

同一个 Agent 面对同一个住宿床位争议、同一块论坛页面时，稳定人物 Profile 和上一时点粒子状态是否真的会约束 LLM 行为，还是模型只会复述公共上下文？

实验固定 12 个 Agent 和同一个 Tick 3 世界，对每人运行四种输入：只看论坛上下文、加入 Profile/利益处境、加入上一时点状态、同时加入二者。四组只改变被检验的信息，论坛帖子、允许动作、随机种子和输出合同保持一致。

## 结果

- 完整条件产生 10/12 个公开行动，纯上下文只有 2/12；提升 66.7 个百分点。
- 完整条件产生 11 个私聊动作，纯上下文只有 1 个；平均每个 Agent 多 0.83 个私聊动作。
- 相对纯上下文，完整条件中 75% 的 Agent 改变了主动作，91.7% 改变了情绪表达，66.7% 改变了是否私聊。
- 条件盲审排除两条四组均沉默、无法辨认的记录后，Profile 因素识别率为 100%，上一时点状态因素识别率为 90%，同时包含二者的完整输入识别率为 90%。
- 留一 Agent 检验每次完全排除目标 Agent：四条件识别率 52.1%（随机基线 25%），Profile 因素与上一时点状态因素识别率均为 70.8%（随机基线 50%）；999 次 Agent 内标签置换的单侧 p 值分别为 0.001、0.002、0.002。
- 12 条记录均承接眼前争议；本轮预审未发现无依据现实事实或统一安全模板。

一个直观例子是“本人申请、替代住处少、材料不齐”的 Agent。纯上下文条件下模型选择沉默；完整条件下，它公开追问排序规则和补材料期限，同时分别私聊熟人核对标准和备用住处。变化不是简单地把语气变激烈，而是把人物处境、当前担忧和可执行动作连接起来。

## 结论

这是一项小规模机制验证，结果是正面的：Profile 与上一时点粒子状态不是后台装饰，它们在相同论坛上下文下能分别、联合改变 LLM 的公开行动、私聊和表达方式，而且这种约束效应在留出陌生 Agent 后仍高于随机基线。它不能替代正式主实验的总体统计，也不证明能准确预测任意陌生 Agent 的具体发言；但足以支持保留这套自然语言人物与状态接口。

## 调用与恢复

实验完成 48 个主槽位，Provider 共结算 53 次请求、197,343 Token，unknown 为 0。5 个格式错误均为已结算结果；自动修复和一次哈希绑定受控修复后完成，已成功槽位未重跑。
