# ForumTwin V5 正式实验结果

## 我们模拟了什么

暑期住宿可用床位从 520 张降至 320 张，而有效申请有 536 份。通知只列出三类优先情形，没有说明类别先后、同类排序、通勤困难证明、补材料入口、截止时间和复核方式。系统从同一 Tick 3 检查点复制出两个平行论坛：Natural 不新增治理；D 允许三个有限观测的 LLM 治理主体动态选择证据更新、服务工单和跨群触达。

## 结果不是‘治理把舆论压下去’

- Natural 最终形成 73 条公开消息、57 条回复、17 个 Claim；D 形成 76 条公开消息、61 条回复、10 个 Claim。治理分支的讨论没有消失，而是收拢到更少的可追踪议题上。
- D 把无依据 Claim 新增速度从 0.111 降至 0.000，把服务积压/SLA 风险从 0.70 降至 0.00，治理观察差从 0.351 降至 0.265。
- 但跨群曝光差从 0.911 升至 0.950；D 的最终信任比 Natural 低 0.054，关切高 0.054。这说明服务动作有效，不等于程序正当性已经被接受。
- 6 条治理消息中 3 条收到严格的直接回复或引用，承接率 50%；两条跨群触达均未获得严格直接承接。

## 论坛里具体发生了什么

治理证据卡说：‘已知床位320张、有效申请536份，三类优先情形已列出；类别及同类排序、补材料入口和截止时间仍待确认。请在治理公告栏发布标准与申诉入口，公布后48小时内由住宿分配复核责任组受理复核。’

居民直接追问：‘床位数和有效申请数先确认了，但我最需要的补材料入口、截止时间，以及三类之间和同类内部的排序规则仍没看到。能否明确什么时候公布？’

服务工单收到的直接反馈是：‘收到登记回执，但现在只确认“会核实”，还不知道三类优先有没有先后、同类怎么排。能否先明确预计反馈时间和补证明的入口，免得大家继续盲等？’

这些回复没有把‘收到通知’误判为‘问题解决’，而是把争议推进到材料入口、截止时间、排序规则和复核责任人。

## 四个维度

- 论坛生态真实性：通过。正式配对运行与已结算、同 Profile/关系/利益/生态发布和 turn-v5 合同的验证面板合计 48 条成熟线程；回复线程占比绝对误差 0.008，线程规模 JS 距离 0.005。`reply-count-detail-v2.json` 同时给出模拟侧精确回复数和3,254条审阅真实线程的脱敏精确分布；真实审阅样本的有回复线程占比为70.7%，中位数为2，90%分位数为9。
- 人物真实性：机制小面板与跨陌生 Agent 的约束效应通过，精确行为预测仍保留边界。312 个正式居民回合中，同一人物纵向语言相似度比匹配的其他人物高 0.0278，95% 区间为 [0.0059, 0.0515]。12 个固定 Agent 的 48 槽四条件配对中，完整输入相对纯上下文使 75% 的 Agent 改变主动作、91.7% 改变情绪、66.7% 改变是否私聊；留一 Agent 的四条件识别率为 52.1%（随机 25%），Profile 和上一 Tick 状态因素识别率均为 70.8%（随机 50%），置换 p≤0.002。这支持约束效应跨 Agent 复现，但不包装成全体人口的精确行为预测。
- 人群异质性：状态层和表达层均通过当前门禁。14 个完整帧覆盖 1,000 个父 Agent 和 10,000 个状态粒子；事件后利益组对 12 维状态的解释度为 7.9%–14.5%，置换检验 p=0.005。312 回合的原始五分类立场为 neutral 174、uncertain 68、mixed 63、support 4、oppose 3；122 个公开表达回合中 mixed 63、uncertain 52、support 4、oppose 3，归一化熵为 0.655。旧的 305/312 是 neutral、mixed 被错误并入 uncertain，已经修正；方向明确的 support/oppose 仍较少，报告不宣称强两极化。
- 治理响应：通过。服务闭环、有限观测、资源守恒、风险预警和严格直接承接门槛均成立；直接承接率为 50%。

维度 2/3 的完整统计见 `fidelity-evaluation-v3.json`；`persona-consistency-v3.svg`、`population-heterogeneity-v2.svg` 和 `particle-distributions-v2.svg` 可直接用于报告。`anonymous-particle-panel-v1.npz` 公开14帧、每帧1,000×10×12的匿名粒子状态和权重，供合作者重算分布、父内不确定性和纵向变化；它不含 Agent ID、Profile 连接键、Prompt/响应指纹或同化记录。

## 对治理的真正启发

最有效的不是再发一份笼统公告，而是把三件事连起来：先用工单承接个体困难；再用证据卡明确哪些已确认、哪些待确认；最后把排序、材料、时限和复核入口补成可执行承诺。若跨群触达只复制同一段说明，未覆盖信息弱势群体，系统会出现‘服务队列关闭了，但信任仍下降’的非预期后果。
